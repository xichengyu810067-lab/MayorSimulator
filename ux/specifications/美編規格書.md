# 二、畫面比例與地圖大小

目前地圖太小，右側與中間有大量空白，建築細節看不清楚。

請調整成：

1. 地圖主視窗必須填滿主要遊戲區域。
2. 不要讓城市只擠在左上角。
3. 地圖至少佔整個可用遊戲畫面的 65% 到 75%。
4. 建築物必須放大到能看清門、窗、屋頂、裝飾。
5. 如果 8x8 地圖太小，請使用縮放、鏡頭、置中、背景延伸等方式讓畫面飽滿。
6. 右側資料欄可以縮窄或改成可收合。
7. 左側建築欄可以保留，但視覺要變成遊戲選單，不要像後台表單。
8. 底部月報區可以縮小或收合，避免壓縮主畫面。

驗收標準：

- 打開遊戲時，第一眼應該看到一個完整童話小城市。
- 不應該看到大片空白背景。
- 建築細節必須肉眼清楚可辨識。
- 遊戲主畫面不能像 debug 工具頁面。

# 三、童話城堡風資產要求

請為每種建築建立明確外觀。

住宅：
- 小木屋或童話小屋
- 圓潤屋頂
- 暖色窗戶
- 小煙囪
- 小花圃或木柵欄

社會住宅：
- 比住宅稍大
- 多戶型小屋
- 仍然維持童話村莊風

商店：
- 有招牌
- 有遮陽棚
- 有展示窗
- 可以看出是商業建築

大型商場：
- 不要做成現代百貨
- 請做成童話市集、廣場商館、城鎮商會風格

工廠：
- 不要太現代工業風
- 可以是童話工坊、齒輪屋、煙囪工坊
- 要可愛，不要髒亂

公園：
- 草地、花叢、長椅、噴泉、小樹
- 要有治癒感

體育館：
- 可以做成圓頂競技場、小型騎士訓練場、童話運動場

學校：
- 像童話學院
- 有鐘樓、旗幟、書本符號或小庭院

圖書館：
- 像魔法圖書館
- 有拱窗、書本招牌、暖色燈光

醫院：
- 可愛療癒小屋
- 不要現代醫院大樓
- 可以有藥草、十字招牌、白色屋頂

警局：
- 可以做成城鎮守衛所
- 有小旗幟、盾牌、哨塔元素

# 五、NPC 與通行邏輯

目前 NPC 不能只是畫在地圖上的小符號。

請改成：

1. NPC 有可辨識的人物外觀。
2. NPC 尺寸要比建築小，但仍然看得清楚。
3. NPC 要有簡單 idle 狀態。
4. NPC 走路時要有簡單動畫。
5. NPC 應該優先走道路或空地。
6. 如果某個地塊上有建築物，NPC 絕對不能穿越那個地塊。
7. 建築物佔用的 tile 必須加入 collision / blocked 狀態。
8. 尋路系統必須避開 blocked tile。
9. NPC 可以在建築入口附近停留，但不能站在建築中心或穿過建築。

驗收標準：

- NPC 不會從房子、商店、工廠、公園建築主體中穿過。
- NPC 看起來像在城市中活動，而不是隨機貼在格子上。
- 建築物會自然阻擋角色路線。
