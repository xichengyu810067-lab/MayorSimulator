# 遊戲大更動詳細記錄

## 更動目標
為了將 Godot 預設的 2D 向量繪圖風格轉換為類似 ChatGPT 生成的 AI 概念圖（擁有立體光影、高對比度、油畫與水彩筆觸、以及強烈的童話氛圍），我執行了一次全域的視覺後製升級。

## 更動限制與原則
- **100% Godot 原生實作**：未依賴任何外部生成圖片、Python 腳本或外掛，完全使用 Godot 的 `ShaderMaterial` 撰寫 GLSL/Godot 著色器來達成視覺效果。
- **功能零破壞**：完全沒有修改任何遊戲的邏輯層程式碼（例如建造系統、尋路系統、滿意度計算）。
- **介面清晰**：特效僅套用於遊戲場景（`map_stage`），確保 UI 介面（如文字、按鈕）不受模糊與顏色轉換影響，維持操作的清晰度。

## 具體更動內容

### 1. 新增後製著色器 (Post-Processing Shader)
- **檔案路徑**：`scripts/rendering/painterly.gdshader`
- **實作細節**：
  - **油畫筆觸效果 (Painterly Effect)**：透過採樣周圍 9 個方向的像素並取最高亮度 (Max Luminance) 的顏色來達成類似 Kuwahara Filter 的塗抹感，讓幾何邊緣變得像是畫布上的筆觸。
  - **柔光與光暈 (Bloom)**：使用多重採樣模糊演算法產生疊加的光暈效果，營造童話般夢幻的發光感。
  - **色差與鏡頭感 (Chromatic Aberration)**：在邊緣加入了微小的紅藍色偏移，模擬 AI 生成圖像中常見的鏡頭質感。
  - **電影級調色 (Color Grading)**：將整體畫面對比度提升 25%、飽和度提升 45%，並加入黃金時刻的暖色調（Warm Tone filter）。
  - **暗角效果 (Vignette)**：在畫面四角加入柔和的暗角，將玩家的視覺焦點引導至中央的城市。

### 2. 修改主程式以套用著色器
- **檔案路徑**：`scripts/app/main.gd`
- **實作細節**：
  - 在 `_build_map_panel()` 函式中，當建立完背景 (`city_backdrop`)、網格層 (`tile_layer`) 與 NPC 層 (`npc_layer`) 後，於 `map_stage` 最上層動態生成了一個 `ColorRect`。
  - 將其 `mouse_filter` 設為 `IGNORE` 以確保不阻擋玩家點擊地塊的行為。
  - 將剛寫好的 `painterly.gdshader` 載入為 `ShaderMaterial` 並套用於這個 `ColorRect`。
  - 此設計利用了 `hint_screen_texture`，讓 Shader 能夠即時捕捉其下方的整個地圖畫面並套用油畫濾鏡。

## 總結
透過這項升級，原本扁平、單純的幾何繪圖現在會透過顯示卡的 GPU 即時運算，轉化為具有高度細節與夢幻氛圍的 2.5D 童話畫風。您的建造功能與遊戲邏輯完全保留，僅是一層魔法濾鏡改變了世界的樣貌！
