# Mayor Simulator Art Direction / Style Guide

## 1. 視角規格

- 採用 2.5D isometric city builder 視角。
- 地圖邏輯維持 8 x 8，但玩家看到的是等角地形與建築，不顯示硬格線。
- 地塊中心點以菱形 tile 對齊，建築、NPC、props 依 y 座標排序，產生前後遮擋感。
- 攝影機預設固定俯視斜角，不做自由 3D 鏡頭。

## 2. Tile 與 Sprite 尺寸

- 邏輯 tile：1 格。
- 視覺 tile：建議 128 x 72 px 等角菱形。
- 空地/道路/草地 tile：128 x 72 px。
- 小型建築 sprite：96 x 96 px。
- 中型建築 sprite：128 x 128 px。
- 大型建築 sprite：160 x 144 px，可跨越單格視覺高度但仍占 1 格邏輯。
- NPC sprite：32 x 48 px。
- UI icon：24 x 24 px 與 32 x 32 px 兩套。

## 3. 建築比例

- 住宅、商店、公車站：tile 高度的 0.9 至 1.2 倍。
- 學校、圖書館、醫院、警局、消防局：tile 高度的 1.3 至 1.6 倍。
- 大型商場、體育館、市政府、機場：tile 高度的 1.8 至 2.2 倍。
- 工廠、發電廠、瓦斯場、自來水廠：體積偏寬，輪廓需明顯但避免陰暗寫實。
- 建築底部需有柔和投影，避免像 UI 貼片。

## 4. NPC 比例

- NPC 高度約為住宅高度的 35% 至 45%。
- NPC 需要有職業辨識點：
  - 一般居民：圓帽、暖色衣服。
  - 學生：書包或制服元素。
  - 商人：圍裙、領帶或招牌色。
  - 老年居民：眼鏡、柔和灰藍服裝。
  - 工人：工帽、工作服。
  - 公務人員 / 議員：徽章、正式服裝或披帶。
- NPC 不顯示大文字標籤，名稱只放 tooltip 或對話框。

## 5. 色票與陰影方向

- 主色：草地綠 `#8BCF5A`、天空藍 `#8FD2FF`、石磚暖灰 `#B6A182`。
- 建築暖色：米白 `#FFE8B8`、淡黃 `#FFD88A`、淡粉 `#FFC9DA`。
- 屋頂色：藍 `#2E7AE0`、紅 `#D63838`、綠 `#349455`、紫 `#854DC7`、粉 `#F27AA8`。
- UI 羊皮紙色：`#F6E8C7`，邊框木色 `#8D6A3A`。
- 陰影方向：光源由左上往右下照射。
- 所有建築右下側加柔和陰影，陰影透明度 18% 至 28%。
- 禁止整體過暗或高對比寫實風，維持可愛、明亮、童話城堡風。

## 6. 地圖圖層

1. `ground`：草地、花草地、廣場地面、工業地面。
2. `road`：石磚道路、路口、廣場連接路。
3. `building_shadow`：建築投影。
4. `building`：住宅、商業、公共設施、行政建築。
5. `props`：樹木、長椅、噴泉、路燈、旗幟、花圃。
6. `npc_shadow`：NPC 腳下陰影。
7. `npc`：居民、學生、商人、工人、議員等角色。
8. `effect`：建造光點、煙囪煙霧、噴泉水花、旗幟飄動。
9. `ui_world`：建築 hover、選取框、對話氣泡。
10. `ui_hud`：資金、日期、人口、建築選單、月報、法案面板。

## 7. 建築素材清單

- 住宅：藍頂小屋、煙囪、花窗、花圃。
- 商店：彩色遮棚、招牌、櫥窗。
- 大型商場：童話商業館、拱門、彩旗。
- 工廠：童話工坊、煙囪、齒輪、柔和煙霧。
- 公園：樹木、花圃、長椅、噴泉。
- 體育館：圓頂競技館、彩帶、看台入口。
- 學校：小鐘樓、學院主樓、書本裝飾。
- 圖書館：石造館舍、柱廊、書卷標誌。
- 醫院：白色柔和建築、紅十字、圓角屋頂。
- 警局：深藍秩序建築、盾牌徽章、燈塔感。
- 後續補齊：消防局、公車站、捷運站、停車場、發電廠、自來水廠、垃圾處理場、瓦斯場、機場、市政府。

## 8. UI HUD 改版規格

- 中央城市地圖是主視覺，UI 面板只能輔助操作。
- 左側：建築選擇與財政法案 tabs，寬度控制在畫面 25% 內。
- 右側：城市數據與族群滿意度，寬度控制在畫面 20% 內。
- 底部：月報採可收合公告板，不長期壓縮地圖高度。
- 建築資訊：點擊建築後以右下角羊皮紙資訊卡顯示。
- 按鈕風格：木框、羊皮紙底、明確 hover 高亮。
- 地圖互動回饋：hover 高亮 tile、選中建築金色描邊、建造時彈出與光點。

## 9. 分階段重構順序

1. 完成真正等角地形與道路層。
2. 將主要建築替換為正式 sprite 或一致的程式化 sprite。
3. 加入 NPC 圖像、移動、點擊對話與停留點。
4. 補建造動畫、煙霧、旗幟、噴泉、雲朵等生命感。
5. 將屋頂、牆面、裝飾、建築變體客製化接到 sprite 材質或替換圖。

## 10. 驗收一句話

玩家第一眼應該覺得：這是一款可愛童話城堡風的 2.5D city builder，而不是一個用格子和文字做出來的 debug prototype。
