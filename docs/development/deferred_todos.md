- [ ] 建立自由文字法律的 AI 閘道與能力／健康檢查。
- [ ] 主要路徑：外部模型檢查法律文字與玩家所選分類標籤的語意一致性。
- [ ] 候選後援：先驗證既有內部摘要模型是否適合法律多標籤判定；未通過驗證時不得宣稱為可用後援。
- [ ] 硬性降級：外部模型不可用且內部模型不適用時，停用自由文字輸入，只保留預設法案。
- [ ] 法律實際模擬效果永遠由確定性的規則引擎與分類標籤執行，模型不得直接改寫遊戲狀態。
