# Mayor Simulator MVP

This Godot version keeps the first playable prototype small:

- 5 x 5 city grid.
- Six building types.
- Tax rate from 0% to 30%.
- Four policy toggles.
- Group satisfaction model.
- Monthly settlement report.
- Ranking score and city rating.

Run with:

```powershell
& "C:\path\to\Godot_v4.7-stable_win64_console.exe" --path "C:\path\to\MayorSimulator"
```
