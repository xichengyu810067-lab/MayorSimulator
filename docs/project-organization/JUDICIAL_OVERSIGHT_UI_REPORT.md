# 司法與監察獨立 UI 實作報告

## 完成內容

- 市政中心由五張功能卡調整為六張 3 × 2 圖像卡。
- 原「司法與監察」合併入口拆為「法院審判」與「監察質詢」。
- 法院使用法官席、市長與辯護人的原創插圖；監察使用委員質詢席、麥克風、市長答辯席與證據放大鏡的原創插圖。
- 兩頁皆以 220 × 220 大型插圖為第一視覺，文字只保留席次、任期、案件狀態與必要操作。

## 遊戲流程

### 法院審判

玩家違法強制施行法案後，司法案件會出現在法院頁。玩家可查看裁決日與嚴重度，並從公共利益、財政緊急、公共安全三種策略中提出辯護。選擇會保存於案件並影響最終裁決。

### 監察質詢

玩家因行政行為遭調查或面臨彈劾時，監察案件會出現在監察頁。玩家可查看指控、證據強度與表決日，並從完整揭露、程序答辯、主動改正三種策略中答辯。選擇會保存於案件並降低彈劾支持分數。

## 驗證結果

- 市政中心固定顯示六張插圖卡，法院與監察各有獨立圖片與提示。
- 法院與監察頁各顯示一張大型插圖、三個辯護按鈕及所屬委員名單。
- UI 擷取測試實際建立兩種案件、各提交一次辯護，並確認選中狀態。
- 司法與監察、主畫面整合、下議院、人口、系統、垂直切片六組測試均通過。
