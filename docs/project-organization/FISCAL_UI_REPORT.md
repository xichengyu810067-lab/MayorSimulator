# 稅率與公共收費 UI 驗收報告

日期：2026-07-22

## 介面改造

- 原本同頁列出 14 個控制，改為 6 個分類：居民稅、產業稅、水電、環境能源、交通收費、社會服務。
- 每類只顯示 2–3 個選項；1280 × 800 邏輯解析度下不需要上下捲動。
- 右側固定顯示預估月收入、市政月支出、預估月淨額與安全緩衝。
- 每列只保留目前收入、設施狀態、相較建議值的淨額差與民意／收入缺口。

## 預警模型

所有預測都只替換目前正在評估的選項，其餘稅率、費率、建築、人口、政策與法案保持不變。

- 綠色：建議範圍，或低價仍可由現有財政安全承擔。
- 黃色：目前值低於建議值 75%，而恢復建議值能實際增加月淨額，且全城安全緩衝不足或單項收入缺口達到實質門檻。
- 紅色：目前值高於建議值 125%，已進入居民負擔、需求下降或產業活動衰退區間。
- 安全緩衝：每月固定支出的 10%，最低為 $100。
- 單項實質缺口：安全緩衝除以 14，最低為 $25。

預估月淨額沿用遊戲既有公式，包含稅收、商業與工業活動、公共事業效率、服務需求、建築維護、政策支出與法案支出。

## 實玩驗證

| 情境 | 結果 |
| --- | --- |
| 全部設為 0 | 11 個有邊際收入缺口的選項變黃；3 個沒有對應設施／收入影響的選項維持正常。 |
| 全部設為建議值 | 14 個選項全部為綠色。 |
| 全部設為最大值 | 14 個選項全部為紅色。 |
| 分類可見列數 | 每頁最多 3 列。 |
| 垂直捲動 | 關閉；所有分類仍可完整操作。 |

零費率測試時，預估月淨額為 $915，安全緩衝為 $138；因此右側全城財政仍顯示安全，但水電等具有明確單項收入缺口的控制會個別顯示黃色，避免把交叉補貼誤判為該費率充足。
