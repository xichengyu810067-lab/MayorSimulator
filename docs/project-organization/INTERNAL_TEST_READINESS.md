## 已驗證的玩家流程

1. 開啟遊戲後選擇新遊戲或繼續遊戲，兩條路徑均先播放載入進度動畫。
2. 從市政中心選擇建築分類與建築。
3. 設定材質、規模、樓層、人力與裝飾。
4. 送審後立即看到收件確認、剩餘遊戲日與現實時間。
5. 審核中無法重複送件。
6. 核准後回到地圖選擇空地開工。
7. 使用共用工程隊完成施工。
8. 點擊既有建築操作樣式、屋頂、外觀、維護與拆除。
9. 民情中心自動顯示全部有效 NPC 陳情並可直接受理。
10. 自動時間以現實 120 秒推進一日，初始畫面、失焦與離開時暫停。
11. 新遊戲立即建立空白進度；每 10 分鐘、完成狀態操作、觸發遊戲事件與離開時自動儲存。
12. 繼續遊戲可還原日期、國庫、建築、施工、NPC、治理案件、稅費、政策、主題、建築外觀及月報。

## 內測前置條件

### 可以立即開始

- 由開發機使用 Godot 專案執行，或由測試主持人操作同一環境。
- 可分配新遊戲與繼續遊戲兩種 30–60 分鐘測試任務。
- 第一輪聚焦核心循環理解度，以及日期、建築、人口、施工與治理的續玩還原。
- 建議 3–5 名內部測試者，每人獨立記錄卡點、誤解與操作時間。

### 擴大內測前必須補齊

1. 安裝 Godot 4.7 Windows 匯出範本並產出可重現的測試版執行檔；目前匯出會因缺少 `windows_debug_x86_64.exe` 與 `windows_release_x86_64.exe` 失敗。
2. 增加最小化首次遊玩引導，至少涵蓋市政入口、藍圖送審、等待核准、空地開工及民情處理。

## 第一輪建議任務

| 任務 | 成功標準 |
| --- | --- |
| 找到民情中心並受理一件陳情 | 不依賴口頭提示，3 分鐘內完成 |
| 選擇商店並完成藍圖送審 | 能說明目前為何不能立刻施工 |
| 辨識審核剩餘時間 | 能正確回答遊戲日與現實分鐘 |
| 核准後在空地開工 | 不誤點既有建築，知道工程隊限制 |
| 調整一項稅率或公共事業費 | 能理解黃色與紅色預警 |
| 點擊既有建築完成一次外觀變更 | 能找到五項建築情境控制 |
| 找到政策、法院與監察三個獨立頁面 | 能正確說明各自用途 |

## 停止測試條件

- 藍圖送審後未建立案件或沒有任何畫面回饋。
- 日期無法自動推進，或失焦期間仍大量補算時間。
- 玩家無法完成施工、受理陳情或返回地圖。
- 同一操作產生重複案件、重複扣款或存檔損壞。
