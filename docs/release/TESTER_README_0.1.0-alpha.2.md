# Internal Tester README — 0.1.0-alpha.2

## Scope

Windows x64 INTERNAL-ONLY Alpha package. Do not upload, share outside the
authorized group, or treat it as a public build.

## Minimum smoke

1. Unzip to a local writable folder.
2. Start `MayorSimulator.exe`.
3. Create/load a city, place or inspect a building, and exercise core HUD.
4. Save, exit normally, restart, and confirm the saved state returns.
5. Use `BUG_REPORT_TEMPLATE.md` for defects; remove credentials and personal
   documents from attachments.

## Language note

Automated localization checks are not manual five-language GUI certification.
zh-TW, zh-CN, English, Japanese, and Korean visual/input behavior is
experimental until click-through evidence exists for this exact RC.

## Restrictions

- Windows x64 only; Linux is neither supported nor delivered.
- Public release is NO-GO due to rights blockers.
- Package is unsigned.
