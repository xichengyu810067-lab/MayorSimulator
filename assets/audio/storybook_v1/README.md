# Storybook audio provenance

All files in this directory are original deterministic PCM synthesis generated
for this project by `tools/audio/generate_storybook_audio.py` on 2026-07-31.
No third-party recordings, samples, melodies, or sound libraries are used.

- `mayors-dawn-loop.wav`: quiet civic-fantasy background loop
- `ui-click.wav`: compact button confirmation
- `page-turn.wav`: tutorial page transition
- `success-chime.wav`: general success feedback
- `construction-complete.wav`: building completion cue
- `warning-soft.wav`: non-destructive warning cue
