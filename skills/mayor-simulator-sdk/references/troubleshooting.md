# Troubleshooting

| Symptom | Likely cause | Corrective action | Proof required |
| --- | --- | --- | --- |
| SDK wrapper says Python is missing although a Python executable exists | Python is outside `PATH`, the project lacks `.venv`, or sandbox policy rejects a discovered executable | Let `mayor-sdk.ps1` probe `MAYOR_SDK_PYTHON`, project `.venv`, `PATH`, the Codex bundled runtime, and local installs; preserve probe failures so access denied is not reported as absence | `doctor` runs through the wrapper and reports the selected Python version |
| `Failed to open 'user://logs/...log'`, sometimes followed by signal 11 | Godot user-data path is unwritable | Use the SDK or existing runner so `APPDATA`, `LOCALAPPDATA`, and `--log-file` point to writable isolated paths | Rerun the same gate; require exit 0 and clean product diagnostics |
| `Access denied` or `存取被拒` under `C:\tmp` or a requested folder | Sandbox or filesystem permission mismatch | Use a confirmed writable project `.tmp` path, or request only the exact required external path | Target exists and the intended executable or artifact is runnable/readable |
| Godot starts headless but the UI claim is uncertain | Headless verifies parse/runtime contracts, not appearance or mouse interaction | Run `ui-qa`, inspect the PNGs, and perform required real clicks | Relevant screenshots, traversal log, and no clipping/overlap/mixed-language text |
| Screenshot says 1280×720 but a fullscreen desktop was captured | OS window mode overrode the requested size | Verify actual PNG dimensions and window state; do not label monitor-sized fullscreen evidence as a requested window size | PNG dimensions and visible window evidence match the acceptance condition |
| Dynamic English/Korean/Chinese UI still contains Traditional Chinese | A formatted runtime string was passed to localization after interpolation | Localize a stable template key and each variable label before formatting | Five-locale page traversal plus localization tests |
| Localized chart or status text throws a `%` formatting error while the test appears green | A translation added, removed, or reinterpreted a format placeholder and the runner only checked the success marker | Compare placeholder signatures per locale and scan runtime diagnostics before accepting the pass | All affected locales render with the same placeholder contract and zero formatting errors |
| GDScript `RegEx` rejects a `\u` range | Godot `RegEx` does not implement the attempted escape pattern | Inspect characters with `unicode_at()` and a curated language-specific set | Localization audit passes without false negatives |
| Building count or visual test drifts after catalog changes | A test or mapping contains a magic count or incomplete chain | Derive expectations from the registry/manifest and compare definitions, IDs, visual entries, and draw branches | Full-catalog contract test and visible placement proof |
| Population or city state changes then reverts | Two systems write the same state and a later sync overwrites the first | Establish one authority; add build, demolish, day-advance, load, and save regressions before changing ownership | Focused regression plus assertion matrix |
| `ObjectDB instances leaked`, resource leak, or `Leaked instance` | A test exits without freeing nodes/resources or leaves a process active | Use the shared cleanup helper, await queued frees, and ensure the runner owns process cleanup | Runner leak check is clean and no related Godot process remains |
| `Failed to read the root certificate store` on Windows | Known Godot environment diagnostic | Preserve and classify it separately; do not hide it or confuse it with a product error | Runner summary shows the known diagnostic and zero product diagnostics |
| Export fails or templates are not found | Missing or mismatched Godot 4.7 Export Templates | Install the exact matching template version into the isolated export app-data root | Template hashes/version pass and expected export binaries are produced |
| Export log reports `Orphan StringName` only with `--verbose` | Godot 4.7 verbose shutdown diagnostics are contaminating the release log | Reproduce with the same source using non-verbose export; keep all normal error, warning, and leak gates | A fresh complete release run passes without adding a diagnostic whitelist |
| A release directory exists but evidence is incomplete | Partial, stale, or manually assembled outputs were reused | Start with new output and app-data roots; run the authoritative `build` flow once | Atomic `release-evidence.json` from the same run |
| Linux staging exists locally but Linux release is claimed verified | Export presence was mistaken for runtime evidence | Run the GitHub Ubuntu job or another real Linux smoke environment | Successful Linux smoke markers and retained CI evidence |
| Python asset tool reports `No module named PIL` | Pillow is optional and not installed in that Python environment | Install Pillow into the selected development environment only; do not add it as a game runtime dependency | Re-run the specific asset tool and its validator |
| SDK `self-test` reports missing skill references or CI gate | Manifest, skill, or workflow changed without coordinated updates | Update `sdk/manifest.json`, affected reference, and CI line together | SDK unit tests, self-test, and `quick_validate.py` all pass |
| `.git` exists but SDK reports `invalid_or_empty` | The directory is only a placeholder and lacks a valid `HEAD` | Do not claim commit, tag, branch, remote, or CI traceability; initialize Git only when the user explicitly requests it | `version` reports `repository` or `worktree`, and Git can resolve a commit |
| SDK called from a linked worktree identifies its parent `.worktrees` directory as the project | The standalone SDK was invoked without the linked worktree root, so automatic detection followed the SDK location instead | Use SDK 1.2.1 with `--project-root <linked-worktree>` before the subcommand, or let `scripts/invoke-sdk.ps1` set process-local `MAYOR_PROJECT_ROOT` | `version --json` reports the linked worktree as `project_root` and Git status `repository` |
| Linked worktree emits Git dubious-ownership or an `initialized_unborn` warning | Git was not queried against the exact worktree, or an old SDK treated a linked `.git` file like an unborn repository | Use SDK 1.2.1, which probes `git -c safe.directory=<exact-project-root> -C <exact-project-root>`; do not add global safe-directory trust | `version --json` identifies the exact linked worktree and its resolved `HEAD`; `initialized_unborn` is reserved for an actual initialized repository without a commit |
| Vehicles animate on isolated map tiles before the player creates a route | Ambient rendering was mistaken for transport simulation | Separate network topology from drawing; require compatible connected endpoints and an active route before spawning vehicles or revenue | Topology tests, route activation tests, persistence round-trip, and visible route traversal |

Always diagnose with the smallest reproducible gate. Preserve the first failing logs, change one causal layer, and rerun into a new evidence directory.
